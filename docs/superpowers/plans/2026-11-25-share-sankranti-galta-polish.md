# Share, Sankranti, Galta Ji, Phone Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** Give visitors things worth posting on Instagram (postcards, a Darshan card, links that preview well), make
Makar Sankranti (14 January) the city's big day, add Galta Ji, and make the site feel right on real phones.

**Architecture:** Builds on the live app (React + Three.js frontend on GitHub Pages; Cloudflare Worker + DistrictDO/
InboxDO/GateDO + D1, migrations 0001–0008, 0010, 0011 deployed). Mirrored files (protocol, filter, benches/stamps/taxi
json) stay byte-identical (`scripts/check-protocol.mjs`). Festival ids beyond the first six reach only `/api/city?v=2`
clients (docs/deployment.md). Deploy order: migrations by hand, `wrangler deploy`, then dispatch the `pages` workflow.

**Spec:** `docs/superpowers/specs/2026-11-14-gulabi-gali-design.md` + owner choices on 2026-11-25.

## Global Constraints

- Privacy: nothing shared or previewed names, locates or pictures a person who did not choose it; a shared card carries
  no account id; ghosts, hidden and blocked people are never shown, counted per person, notified about, or reachable.
- Phones first (360×740, Instagram's in-app browser). `frontend/tests/hud.spec.ts` bounds hold in every district. CI's
  Linux fonts render a few px wider than macOS: leave margin in any HUD-fit change.
- Bilingual copy (Hinglish default + English) in `frontend/src/i18n/strings.ts`, original, respectful of real places,
  faiths and communities; gender-inclusive where a Hindi verb is gendered.
- New user text through the word filter; new writes rate-limited; new schema only in new migrations (0012+).
- No per-frame allocations; dispose on district change; `prefers-reduced-motion`; quality tier 0 thinner; test hooks
  only behind `VITE_TEST_HOOKS`; first-load main bundle stays under 250 kB gzip.
- Workers Free plan is live: little new Durable Object time or per-request fan-out.
- Gate: `npm run lint && npm test && VITE_API_URL=https://api.gulabi-gali.manishbisht.me npm run build -w frontend && npm run check:test-hooks && (cd frontend && npx playwright test)`; e2e independent of live weather, wall-clock speed and the day's goal.

## Review Focus

1. A shared image or preview that leaks a name, a face-like identity, an id, a location of a person, or private data.
2. A district/landmark/festival change that breaks travel, stamps (count change), Darshan, map, signposts, taxi data,
   HUD fit, reachability or old bundles.
3. Festival effects or new scenery that hurt frame rate on low-end phones.
4. Copy about a living pilgrimage site or a festival that is disrespectful or inaccurate.

---

### Task 1: Postcards and the Darshan card (share to Instagram)

- Photo mode gains a "Postcard" frame: a 1080×1920 (Stories) image of the shot with a band "Gulabi Gali · <place> ·
  Jaipur" and the site's address; share with the native share sheet (files) where it works, else save the image.
- The Darshan list gains "Card banao": a 1080×1920 card of the visitor's stamps (collected shown, the rest as outlines),
  their count, the site's address; no name unless they tick "naam dikhao" (first name only, residents only).
- Works in Instagram's in-app browser (no `navigator.share` files there: a saved/long-press image fallback with a hint).

### Task 2: Link previews for places

- Each shareable place gets a static page `/p/<district>/<place>/` (built at site build time from the same data
  `mapItems`/placeLink use) with Open Graph/Twitter tags (bilingual-ish title, a line about the place, an image) that
  forwards to `/?at=<district>:<place>`. "Bulao" and the map share these links; old `?at=` links keep working.
- Images: one 1200×630 picture per landmark/district, generated by a script the owner never has to run by hand (done
  once by the implementer and committed, small JPEGs), plus a site-wide default. No person in any image.

### Task 3: Makar Sankranti

- On Sankranti (the festival calendar's dates) the sky over every district fills with kites (instanced, cheap, drifting,
  some cut ones falling), rooftop viewpoints and roofs feel alive (a few NPC kite-flyers on roofs), and the existing
  patang game is the day's centre: easy to find from the HUD line and the rooftops. Bilingual HUD line; respectful,
  original copy (no other region's catchphrases presented as Jaipur's). Tier 0 thinner; reduced motion steady.

### Task 4: Galta Ji district

- A seventh district `galta` reached by bus: the temple complex in its gorge with the kunds (water colliders), ghats,
  the climb to the Surya Mandir ridge as a viewpoint, monkeys (the bandar or animal systems, switchable like today),
  stalls, benches, poster wall, signposts, taxi, ambience bed; landmark + stamp `galta-ji` (stamps 13 → 14, appended).
- A living pilgrimage site: no depiction of bathing people or worship as spectacle; copy respectful and accurate.

### Task 5: Real-phone polish

- Install to home screen: a valid web app manifest and icons, the service worker installable, a quiet one-time
  "Home screen pe rakho" hint where the browser supports it (never in the Instagram in-app browser; never nagging).
- Instagram's in-app browser: detect it; a gentle "Browser mein kholo" hint where a feature cannot work there.
- Safe areas (notches, home bar) respected by the HUD, sheets and joystick; no accidental zoom/scroll on iOS.
- Low-end Android: a device-perf scenario with heavy CPU throttling across every district; fix what it shows (tier
  steps, draw calls, texture size) and record the numbers in docs/device-performance.md.
